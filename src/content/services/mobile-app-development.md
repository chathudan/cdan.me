I've been building mobile since native Android was still running on Dalvik. Since then: Xamarin, .NET MAUI, native iOS work when needed, and everything that comes with running mobile in production — App Store review, Play Store rollouts, crash monitoring, staged releases, and the eternal fun of keeping two platforms in sync.

## What I bring

- **.NET MAUI &amp; Xamarin** — I led a live production migration from Xamarin to .NET MAUI across both platforms without user disruption. I know where the sharp edges are and how to avoid them.
- **Native when needed** — Android (Kotlin / Java) and iOS (Swift). I've built native modules to bridge into Xamarin / MAUI when the cross-platform layer wasn't enough.
- **Release engineering** — build pipelines, code signing, App Store / Play Store submission, over-the-air updates, phased rollouts, crash reporting.
- **Backend integration** — since I write the backends too, mobile-server integration is genuinely one system, not a hand-off.
- **Third-party integrations** — Firebase, Stripe, PayPal, Recurly billing, VoIP/SIP, WebRTC, push notifications, biometrics, in-app purchase.

## Good fits

- You have an existing Xamarin app and you're worried about the deprecation timeline. I've done this migration on a live platform.
- You need a companion app for an existing backend and you want someone who understands both sides.
- You're validating a mobile-first product and want production-grade code from day one — not something you have to throw away in six months.

Not the right fit for: games, heavy AR/VR, or projects that need a specialist native team of ten.
