I've spent 15 years building the backends that quietly run business-critical operations — video-learning platforms serving half a million users, secure communications systems, B2B systems for enterprise clients. My default stack is C# / .NET / .NET Core on Azure, but I've written production code in Node.js, Java, Python and more when the project asked for it.

## What I bring

- **Architecture:** event-driven microservices on Azure (App Service, Functions, Service Bus, Cosmos DB, Key Vault, AKS). I've stood up 20+ services with zero-downtime deployment on a platform still under active load.
- **APIs:** RESTful design with OpenAPI / Swagger, secure auth via OAuth2 / OpenID Connect, Keycloak, .NET Identity Server, and Azure AD.
- **Data:** MS SQL, PostgreSQL, MongoDB, Cosmos DB. Schema design, migrations, query tuning, and the operational side of keeping databases healthy under load.
- **DevOps:** Azure DevOps CI/CD, Docker, Kubernetes, monitoring with Application Insights, OpenTelemetry, and Grafana.
- **Cloud &amp; hosting:** Azure end-to-end, AWS where it makes sense, and comfortable self-hosting on Linux (Nginx, Let's Encrypt, Fail2Ban) when the situation calls for it.

## Good fits

- Greenfield backends where you need someone who can own the whole path — architecture, code, deployment, monitoring — without asking you to make every technical decision.
- Existing systems that need a senior engineer to stabilise, refactor, or migrate without disrupting users.
- Teams that need a technical lead on a defined scope for a fixed period.

Not the right fit for: small brochure sites (any decent local agency can do those better and cheaper), or work that requires me to sign onto a large enterprise bureaucracy.
